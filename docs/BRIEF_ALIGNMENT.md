# Browser behavior against the challenge brief

Reference: the supplied eight-page *The AI Apprentice* brief, especially pages
3-4 (required modules and Apprentice Test), 5-6 (ElevenLabs), and 7 (demo criteria).

AI is a standard browser capability. Reopening or refreshing does not disable it.
Screen analysis still requires privacy review, approval, and **Analyze approved
frames**. Original media and OCR remain local. Record's optional interjections use
typed and explicit voice notes; screen questions follow approved analysis. This is
the owner's explicit privacy choice. Text is the default question presentation;
Text only / Voice only / Text and voice preferences persist per workflow.

| Brief criterion | Current behavior and remaining acceptance |
| --- | --- |
| When to ask | Note interjections require three seconds without input in the Apprentice page, an idle voice channel, one active question maximum, a 45-second cooldown, and five questions per ten session minutes. This does not detect reading, external-app typing, or speech outside explicit microphone capture. |
| What to ask | Applicable gaps, completeness, criticality and observation confidence select questions. Navigation alone does not justify a question. No artificial question quota is imposed. |
| Capture: three live screen questions including a guardrail | **Not met by the chosen browser privacy flow.** Live questions use notes; screen questions wait for approval. A separately authorized live screen-analysis design and demo would be needed. |
| Debrief: three unanswered follow-ups, confirmed teach-back | Post-analysis entry asks one supported visual question. Debrief continues through unresolved gaps; building the Work Map produces teach-back for expert review. A real demo with three supported gaps and an expert correction remains necessary. |
| Every step/guardrail linked to a screen moment and expert words | Evidence and decision IDs support traceability; approved frames supply screen evidence and answers bind to their questions. Link quality still needs review against a real task. |
| Teach a new case and catch a wrong decision before save | Verified structured exercises and advisory tutoring exist. Browser tutoring does not intercept another application's Save or observe live trainee pixels. The before-save screen-coaching demo remains a gap. |
| ElevenLabs voice agent | Existing ElevenLabs TTS and explicit-answer transcription are used. This is not an ElevenAgents conversation or Scribe v2 Realtime integration; those brief-specific integrations remain separate work. |
| Trust/off-record | Review precedes frame disclosure. Forgetting evidence invalidates dependent knowledge. Confirmed workflow deletion removes hosted data and browser media/review drafts. Already dispatched provider requests cannot be recalled. |

Acceptance for this change covers AI without switches; approved-frame questions
and explicit no-question outcomes; processing feedback across navigation; question
presentation and audio failure fallback; and confirmed deletion from Workflows and
Settings while preserving other workflows. Provider fixtures establish application
contracts, not live model quality, actual ElevenLabs playback, full challenge
acceptance, or Replit publication. See EVALUATION.md and TESTING.md.
